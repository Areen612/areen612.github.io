04 Transcript analysis API FastAPI · Celery · PostgreSQL +

An Arabic and English customer-support transcript analysis prototype. FastAPI accepts jobs, Celery and Redis handle background processing, and PostgreSQL stores status and results. The worker redacts email, phone, and card patterns before LLM analysis, validates structured output, and handles failed jobs. Includes polling, rate limiting, health checks, and metrics.

05 Speechlog Mini — Arabic speech API FastAPI · PyTorch · Whisper +

An audio-to-text pipeline combining resampling, Silero voice activity detection, segment merging, faster-whisper transcription, and Arabic text normalization. Returns timestamped segments through FastAPI, with Common Voice evaluation scripts for word and character error rates. Built as an experimental speech service.

View source on GitHub ↗
06 Route planning with fuel stops Django · AWS Location +

A Django API using AWS Location to calculate driving routes between US locations and select fuel stops using station prices, vehicle range, and detour constraints. Produces an interactive route map and a fuel-cost breakdown.

08 Alzheimer’s MRI classification Python · Deep learning +

09 Transaction fraud detection scikit-learn · LightGBM +

A notebook study comparing logistic regression, random forest, and LightGBM on an imbalanced transaction dataset. Explores stratified splits, robust scaling, SMOTE, and decision thresholds, using precision, recall, F1, and ROC AUC to compare results.
